Thus, per-query speedups and confidence intervals are strictly microarchitecture-controlled.

  1.   2. Queries whose runner assignment shifted between campaign 37758359536 and 37788815352 may show small delta shifts (+/-2-4%) attributable to CPU clock/IPC variation rather than pure software changes.

## 3. RCA Hypotheses Verification

### (a) TPCH q17/q03/q08/q09 and Join Shuffled Hash Queries
*Hypothesis:* Reverting shuffle-probe skip `9cccd0676` via `72981e4c3` restores batch row pruning in shuffled probe joins and improves timing.

- **`join_shuffled_hash__f_sorted__dim_128`:**
  - **Batch Row Pruning:** **CONFIRMED RETURNED.** In candidate_on, `DynamicFilterJoinExec` evaluated **16,000,000 rows** and pruned **15,999,872 rows** (99.999% pruned) in 37 ms. (In campaign 37758359536, the skip logic left batch rows pruned at 0).
  - **Timing:** 0.98x [0.95, 1.00] (new) vs 1.00x [0.73, 1.44] (old). Timing variance narrowed significantly.
- **TPC-H Shuffled Probe Queries:**
  - **`tpch_clu__q08` / `tpch_nat__q08`:** Batch row pruning active! Candidate evaluated 274,357 probe rows and pruned **29,897 rows** in 3 ms. Timing: `tpch_clu__q08` reached **1.01x [0.98, 1.04]** (execution: **1.01x [0.98, 1.06]**, was 0.98x); `tpch_nat__q08` reached **1.02x [0.98, 1.05]** (was 0.99x).
  - **`tpch_clu__q17` / `tpch_nat__q17`:** Candidate native scan runtime filter pruned data upstream at scan level: native bytes read dropped from 306.1 MiB down to 263.2 MiB (`tpch_clu`) and 286.6 MiB to 246.5 MiB (`tpch_nat`), reducing read rows from 35,993,780 to 18,014,000 rows (22 / 8 predicate tasks). Because scan filtering already eliminated the non-matching data, batch join filter evaluated 0 remaining rows. Timing: `tpch_clu__q17` at **0.99x [0.98, 1.02]** (execution **1.00x [0.98, 1.02]**), `tpch_nat__q17` at **0.98x [0.95, 1.00]**.
  - **`tpch_clu__q03` / `tpch_nat__q03`:** Scan runtime filter pruned files at scan level (8 / 10 predicate tasks); batch join filter evaluated 0 rows. Timing: `tpch_clu__q03` improved to **1.01x [0.96, 1.06]** (was 0.98x); `tpch_nat__q03` at 0.97x [0.94, 0.99].
  - **`tpch_clu__q09` / `tpch_nat__q09`:** Scan runtime filter attached (22 / 8 tasks); candidate evaluated 1,942,934 rows (0 pruned, 16 ms overhead). Timing steady at **1.00x [0.98, 1.02]** and **0.99x [0.98, 1.00]**.
